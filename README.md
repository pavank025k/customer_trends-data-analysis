# Customer Behavior Data Analysis

This project analyzes customer shopping behavior to understand purchasing patterns and generate business insights. The analysis uses **Python for data cleaning and exploration, SQL for business queries, and Power BI for visualization.**

## Project Objective
The goal of this project is to convert raw customer transaction data into meaningful insights that can help businesses improve customer engagement and sales strategies.

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib)
- SQL (MySQL)
- Power BI
- Jupyter Notebook

## Project Workflow

### 1. Data Preparation (Python)
- Import dataset
- Clean missing or incorrect values
- Perform exploratory data analysis

### 2. Data Analysis (SQL)
- Identify top customers
- Analyze product category performance
- Calculate revenue and purchase metrics

### 3. Data Visualization (Power BI)
- Sales trends
- Customer demographics
- Product category performance dashboard

## Key Insights
- Identified top spending customers
- Found highest revenue generating product categories
- Analyzed customer purchase trends
